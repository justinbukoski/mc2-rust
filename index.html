Start playing in three steps

You need the original game files. The download contains no game data. Use the folder from your own copy of the original game: the one that contains system.cfg and the .fst files, plus its mc2res.dll.

  1. Unpack the download.

    Mac: move MC2 Rust.app anywhere. It is not notarised, so the first time right-click it and choose Open. Windows: unzip it. Linux: tar xzf the file.

  2. Tell it where your game files are.

    Create a text file named mc2.cfg next to the program with one line: data = /path/to/your/game/folder. Other ways are in the install guide.

  3. Play.

    Open the app (Mac), run mc2.exe (Windows) or ./mc2-rust.sh (Linux). The first start spends up to 90 seconds sharpening the textures from your data. Esc or P pauses.

What to expect

Works

  • The single-player campaign engine, missions, mech bay and briefings

Not yet, or not checked

Who made it

Directed by its owner and written almost entirely by AI models: Claude (Anthropic), GPT models via Codex (OpenAI), DeepSeek, Mistral, Grok and locally run Qwen models, working as coders and independent reviewers. See every model and what it did.

Built on the MechCommander 2 source code that Microsoft released under the Ms-SSLPL. alariq's port of the same source was used as a reference for how the game behaves; none of its code is included.
